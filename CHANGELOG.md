# Change Log

All notable changes to this extension are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0]

First release.

- Tasks: run Claude Code sessions as tasks, listed by state in the sidebar
- Task view: streamed output, tool calls, follow-up prompts, model switch
- Approvals: allow, deny with a reason, or always allow in this task; answer questions from Claude
- Diff cards: per-turn file changes with line counts, inline diff, diff editor, revert (no Git required)
- Attachments: right-click "Foreman: Attach to Task" or drop files onto the task view
- Notifications and status bar for waiting, finished and failed tasks
- Persistence: tasks, history and diff cards survive a restart; interrupted tasks resume their session
